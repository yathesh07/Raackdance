# Admin Guide (staff)

Sign in at **raackdance.com/admin**. You only see the modules your role allows.

## Enquiries (Super Admin, Branch Managers, Counsellors)
1. New leads arrive with status **New** (red). Filter by status chips, type, studio, assignee or date.
2. Click a lead → **Call / WhatsApp / Email** buttons, all form details, lead source (UTM / "how did you hear"), landing page.
3. Set **Status**: New → Contacted → Trial Scheduled → Trial Completed → Enrolled (or Not Interested / Invalid / Archived).
4. **Assign** the lead (counsellors can *Assign to me*), set a **follow-up** date/time, and add **internal notes**. Overdue follow-ups turn red.
5. **Export CSV** for reporting. Overview shows the weekly trend, pipeline, sources and top studios.

Branch managers see only enquiries for their studios; counsellors see unassigned leads and their own.

## Content (Super Admin, Content Editors)
- **Programs, Events, Careers, Instructors, Testimonials, Gallery**: Add / Edit / Delete; the eye icon publishes or hides instantly.
- **Studios**: set **Verification status** (Unverified → Active, or Closed to hide). Migration flags are in *Internal notes*. Branch managers can edit their own studio.
- **Class schedules**: choose a studio, add/edit batches (day, program, label, time). Tick *Schedule verified* on the studio once confirmed.
- **Gallery & testimonials — consent**: every photo/quote showing a child needs *Consent obtained* (or *Not required*). *Withdrawn* hides it everywhere. The Overview checklist counts items still *Unknown*.
- **Pages & SEO**: edit each page's search title and description (stay under ~60 / ~160 characters).
- Uploads: JPG, PNG, WebP, AVIF, GIF (≤10 MB) or MP4/WebM (≤100 MB). Prefer landscape photos ≥1600 px wide.

## Super Admin only
- **Users & roles**: invite staff by e-mail, set role, assign studios to branch managers, deactivate leavers.
- **Settings**: phone, e-mails, registration notice, tickets link, optional WhatsApp chat number, homepage headline, stats, social links.
- **Audit log**: who changed what and when (with before/after values).
